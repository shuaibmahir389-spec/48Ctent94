# 48 Mahadi

Deploy-ready static website for the 48 Ctent experience. Includes the site source, assets, and APK download in `downloads/`.

## Publish with GitHub and Vercel

1. Extract this ZIP and upload its contents to the root of a GitHub repository.
2. In Vercel, import that repository.
3. Select **Other** as the framework preset, leave the build command empty, and use the repository root. The site is served from `index.html`.
4. Deploy. The APK download is served from `downloads/`.

For local preview, run `node server.js` from the project root.
